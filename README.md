CCSU自动校园网认证程序 - 技术文档
版本：1.0
适用环境：Android + Termux (无需 Root)
最后更新：2026-09-08

────────────────────────────────────────────

1.项目概述
────────────────────────────────────────────

1.1 背景与痛点
大学校园网通常采用Web Portal认证方式，每次连接Wi-Fi后，用户必须手动打开浏览器，
输入学号和密码才能上网。若手机息屏或Wi-Fi重连，则需重复此操作，体验极差。

1.2 解决方案
本程序运行于Android上的Termux终端环境，通过Python脚本定时向校园网认证网关
发送POST请求，模拟登录过程，从而实现“连接Wi-Fi即自动认证”，无需人工干预。

1.3 特点
● 无需Root权限，仅需安装Termux并配置Python环境。
● 每5分钟自动重认证一次，保持在线状态，防止掉线。
● 详细的日志输出，包括时间、认证结果、错误原因等，便于排查问题。
● 支持常见错误类型识别（密码错误、账号被占用、IP错误等）。
● 配合系统Wi-Fi自动连接功能，可做到“开机即用，永不离线”。

────────────────────────────────────────────

2.工作原理
────────────────────────────────────────────

2.1 认证流程
① 程序启动后读取本地配置文件（包含学号、密码、认证网关URL等）。
② 构造HTTP POST请求，携带账号、密码及其他必要参数（如IP地址、NAS标识等）。
③ 发送请求至认证网关，解析返回的JSON或纯文本响应。
④ 根据响应中的result和ret_code字段判断认证状态：

成功：记录“认证成功”或“已在线（无需重复认证）”。

失败：区分密码错误、账号并发数已达上限、IP地址无效、AC拒绝等原因。
⑤ 将结果及时间戳写入日志文件，同时终端输出简要信息。
⑥ 使用time.sleep(300)休眠5分钟，然后重复步骤②~⑤。

2.2 关键变量说明

interval: 重认证间隔，默认300秒（5分钟）。可根据校园网会话超时策略调整。

auth_url: 校园网认证网关的登录接口地址（需从实际抓包获取）。

请求参数: 通常包含 username, password, ip, nas_id, callback 等，
具体字段因学校而异，本程序采用可配置的模板。

2.3 错误码映射表（示例）

ret_code	含义	日志输出
0	认证成功	认证成功，已上线
1	账号已在线（重复认证）	已在线，无需重复登录
2	密码错误	认证失败：密码错误
3	用户账户被锁定或欠费	认证失败：账号异常
4	用户已在线（达到最大会话数）	认证失败：账号被占用
5	IP地址无效或AC拒绝	认证失败：IP/MAC错误
其他	未知错误	认证失败：未知原因
注：实际错误码需根据学校网关返回的具体字段调整。

3.环境与依赖
────────────────────────────────────────────

3.1 硬件要求

Android 8.0 及以上系统。

支持Wi-Fi连接。

3.2 软件要求

Termux（可从 F-Droid 或 Google Play 下载）。

Python 3.9 及以上（在Termux内安装）。

pip 包：requests（用于HTTP请求）。

3.3 网络要求

必须连接到校园网Wi-Fi（SSID通常为 CCSU-Student等）。

认证网关的IP和端口可达。

────────────────────────────────────────────

4.安装与配置
────────────────────────────────────────────

4.1 安装Termux及Python
① 在Android上安装Termux。
② 打开Termux，执行以下命令更新源并安装Python：
pkg update && pkg upgrade -y
pkg install python
③ 安装库：
pip install requests
pip install netifaces
pip install socket

4.2 获取认证脚本
将主脚本 main.py 和工具脚本 tool.py 复制到Termux的工作目录

5.使用说明
────────────────────────────────────────────

5.1 启动程序
进入脚本目录，执行：
cd ~/Campus-Wifi-Auto-Verify
python main.py

程序将立即执行一次认证，然后进入每5分钟循环。

5.2 后台运行（建议）
使用 termux 使其在后台持续运行：
python main.py

或者安装Termux:Boot插件，让手机开机自动启动该命令。

5.3 查看日志
日志文件默认为 auth.log，可用 cat 或 tail -f 实时查看：
tail -f auth.log

日志每行格式示例：
[INFO] 2026-09-08 14:23:45 main() 认证成功 账户:?
[WRAN] 2026-09-08 14:28:45 get_ip() 最终ip:?(可能错误)
[ERROR] 2026-09-08 14:33:45 main() 认证失败
